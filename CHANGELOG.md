## [Unreleased]

### Added
- **Обязательное меню выбора качества и плеера**: ликвидирован автоматический запуск скачивания при одном стриме; бот всегда формирует интерактивные инлайн-кнопки со всеми доступными вариантами разрешений (4K 2160p, 2K 1440p, 1080p, 720p) и плееров (AnimeLib, Kodik).
- **Поддержка ультравысоких качеств 4K (2160p) и 2K (1440p)**: модуль выбора стримов и конвейер загрузки теперь полностью распознают и обрабатывают разрешения `2160p`, `1440p`, `1080p`, `720p`, `480p`, `360p`.
- **Динамическая сортировка озвучек с приоритетом пользователя**: при формировании карточки серии и вариантов загрузки любимые озвучки пользователя автоматически поднимаются на верх списка со значком `⭐`.
- **Интерактивное управление колокольчиком (`toggle_bell`)**: кнопка `[🔔 Отслеживается]` / `[🔕 Не отслеживать]` в карточке тайтла Telegram-бота для мгновенного включения/отключения уведомлений в локальной базе данных без перехода в браузер.
- **Нативный HLS-конвейер чанков без внешнего FFmpeg**: прямая сборка TS-сегментов и прямое скачивание MP4 через потоки Node.js (`axios` + `stream.pipeline` / `createWriteStream`), гарантирующие независимость от системных бинарников FFmpeg и безопасность на Windows.
- **Метрика свободного места в папке `downloads/`**: блок настроек бота отображает актуальный объем свободного дискового пространства и размер каталога загрузок.

### Changed
- **Официальный рабочий эндпоинт AnimeLib**: все запросы API переведены на стабильный базовый URL `https://hapi.hentaicdn.org/api` с заголовками `Site-Id: 5`, `Origin` и `Referer`.
- **Полноценная пагинация закладок**: глубина сканирования расширена до 25 страниц по 60 записей на страницу с поддержкой всех 5 статусов папок (`watching`, `planned`, `completed`, `dropped`, `on_hold`).
- **Синхронизация планировщика с настройками**: интервал фонового опроса релизов (15, 30, 60 мин, по умолчанию 30 мин) динамически перезапускает таймер при сохранении настроек в Telegram.
- **Честная статистика в гостевом режиме**: при недоступности, отзыве или отсутствии токена Shikimori бот прозрачно информирует пользователя о работе в локальном режиме: `AnimeLib ➔ SQLite [Локальный режим ⏸]`.

### Fixed
- **Принудительный запрос 1080p в Kodik**: парсер Kodik гарантированно запрашивает стрим в максимальном качестве 1080p (добавление `/1080p` в endpoint серии и нормализация качеств), исключая дефолтный даунгрейд до 720p.
- **Отображение запланированных при отсутствии колокольчиков**: если при фильтре по колокольчику найдено 0 тайтлов, бот не прячет список, а автоматически выводит все тайтлы из папки «Запланировано» с кнопкой «Показать все запланированные (X)».
- **Устранены сетевые ошибки DNS ENOTFOUND**: вычищены устаревшие и неработающие домены (`video.animelib.me`, `cache.lib.social`, `anmli.org`), приводившие к сбоям резолва ссылок плееров.
- **Ликвидирован риск Out-Of-Memory**: загрузка тяжелых серий (включая многогигабайтные 1080p и 4K) переведена на потоковую передачу данных через `stream.pipeline` с контролем backpressure и буферизации.
- **Корректное сохранение состояния фильтра колокольчика**: устранена проблема сброса фильтрации по колокольчику при пагинации страниц в разделе «Запланированное».

### Removed
- **Устаревший монолитный код и мертвые вызовы**: удален устаревший сервис `animelibService` старой архитектуры.
- **Блокирующие сетевые пинги CDN**: устранены предварительные блокирующие HTTP-проверки CDN в `BaseSourcePlugin`, вызывавшие задержки и таймауты при генерации меню серий.

## [2.1.0] - 2026-09-13

### Added
- Полная детализация профиля по категориям (`👤 Профиль`): Смотрю, В планах, Просмотрено, Любимые, Пересматриваю, Отложено, Брошено, FATE.
- Журнал фоновых проверок серий (Check Reports & Scheduler) в таблице `check_reports`.
- REST эндпоинт `GET /api/library-stats` для веб-панели управления.

### Changed
- Тайтлы взрослой категории строго изолированы и исключены из всех статистик и рекомендаций.
